=====================================
  FLEURMAT — INSTALLATION SUR UN PC
=====================================

Fonctionne sur Windows et Mac.

PRÉREQUIS
---------
- Node.js 20 ou supérieur : https://nodejs.org
- Git : https://git-scm.com


ÉTAPES D'INSTALLATION
----------------------

1. Cloner le projet
   Ouvrir un terminal et taper :

       git clone https://github.com/tomvivian28072005/fleur-mat.git

   Le dossier "fleur-mat" sera créé dans le répertoire courant.

2. Installer les dépendances

   Windows :
       cd fleur-mat\admin
       npm install

   Mac :
       cd fleur-mat/admin
       npm install

   Attendre la fin du téléchargement (1-2 minutes).

3. Créer le raccourci de lancement

   Windows :
       - Aller dans le dossier "fleur-mat"
       - Clic droit sur "Lancer Admin.bat" → "Envoyer vers > Bureau (créer un raccourci)"

   Mac :
       - Ouvrir le Terminal
       - Rendre le fichier exécutable (une seule fois) :
             chmod +x /chemin/vers/fleur-mat/Lancer\ Admin.command
       - Glisser "Lancer Admin.command" dans le Dock ou sur le Bureau

4. Premier lancement
   - Double-cliquer sur le fichier de lancement
   - L'admin s'ouvre sur http://localhost:5173
   - Une fenêtre de configuration apparaît
   - Cliquer "Détecter" — les champs se remplissent automatiquement
   - Cliquer "Enregistrer"

   C'est prêt !


WORKFLOW QUOTIDIEN
------------------
1. Lancer l'admin (double-clic sur le raccourci)
2. Ajouter / modifier / supprimer des plantes
3. Ouvrir un terminal dans le dossier fleur-mat et pousser les changements :

       git add data/plantes.json images/
       git commit -m "Mise à jour catalogue"
       git push

4. Le site public est mis à jour en 1-2 minutes.


DÉPANNAGE
---------
- "npm n'est pas reconnu" → Node.js n'est pas installé (voir Prérequis)
- "git n'est pas reconnu" → Git n'est pas installé (voir Prérequis)
- Mac : "permission denied" sur le .command → relancer le chmod +x (étape 3)
- La fenêtre se ferme immédiatement → lancer depuis un terminal pour voir l'erreur :

   Windows :
       cd chemin\vers\fleur-mat\admin && npm run dev

   Mac :
       cd chemin/vers/fleur-mat/admin && npm run dev

- Le site ne se met pas à jour → attendre 2 min après le push, puis F5
